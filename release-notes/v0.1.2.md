# PhiReader v0.1.2

## 中文

### 新增

- 新增 GitHub 反馈入口：可从论文库直接提交问题或功能建议。
- 反馈页面会预填 PhiReader 版本、界面语言和运行环境，方便复现与定位问题。
- 新增中文 Bug 报告和功能建议模板，并提醒提交者不要上传包含隐私或未公开内容的论文。
- Tauri 桌面版新增安全的外部链接打开能力。

### 维护

- 忽略宣传素材目录，避免构建和开发产物进入版本控制。

## English

### Added

- Added a GitHub feedback entry point so users can submit bug reports or feature requests directly from the paper library.
- Feedback pages are prefilled with the PhiReader version, interface language, and runtime to make reproduction and triage easier.
- Added Chinese bug-report and feature-request forms, including a reminder not to upload private or unpublished papers.
- Added a secure external-link opener for the Tauri desktop app.

### Maintenance

- Ignored the promotional-artifacts directory so generated materials stay out of version control.
