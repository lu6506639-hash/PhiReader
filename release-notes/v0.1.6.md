# PhiReader v0.1.6

## 中文

### 修复

- 修复 Windows 桌面端 API Key 显示已保存、生成摘要时却提示未配置的问题。
- API Key 现在会写入 Windows Credential Manager，并增加跨凭据实例读取的回归测试。

## English

### Fixed

- Fixed API keys appearing saved on Windows while summary generation still reported them as not configured.
- API keys are now stored in Windows Credential Manager, with regression coverage for reading them from a new credential instance.
