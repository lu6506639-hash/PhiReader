# PhiReader v0.1.3

## 中文

### 修复

- 修复导入论文解析时短暂弹出命令行窗口的问题。
- 修复进入阅读页时页面渲染和缩略图渲染弹出大量命令行窗口的问题。
- Windows 下的 Python 解析器和打包解析工具现在都会以隐藏控制台模式运行。

## English

### Fixed

- Fixed transient command-line windows appearing while importing and parsing papers.
- Fixed multiple command-line windows appearing when opening the reading view for a parsed paper.
- Python-based and bundled parser helpers now run with hidden consoles on Windows.
